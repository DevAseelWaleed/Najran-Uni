# دليل المدير

ابدأ بتهيئة المدير كما في README ثم سجّل الدخول باسم المستخدم أو البريد وكلمة المرور. افتح البريد التطويري للرمز فقط محليًا؛ في الإنتاج يصل إلى بريدك. الرمز صالح خمس دقائق، خمس محاولات، ويمكن إعادة إرساله بعد دقيقة.

في الإعدادات، أضف أسماء الكليات والأقسام واضبط الاسم واللون ورابط الشعار الرسمي. الصورة البديلة الحالية ليست شعارًا رسميًا.

أنشئ مستخدمًا عبر صفحة المستخدمين. تصله رسالة تهيئة كلمة المرور؛ إذا تعذر التسليم يظهر تنبيه ويمكن إعادة إرسال الرابط من ملف الحساب. الموظف يدير أعضاء الهيئة والاستيراد والتصدير، المشاهد يقرأ فقط. لا يمكن تعطيل آخر مدير نشط.

إضافة عضو: املأ الحقول ذات النجمة، ثم احفظ. أضف المؤهلات الإضافية في النموذج. بعد الحفظ استخدم تبويب المرفقات لرفع الملفات. الصورة الشخصية تقبل JPEG/PNG. لا تُرسل مستندات الجامعة إلى خدمات خارجية غير معتمدة.

البحث والفلاتر محفوظة في عنوان الصفحة. التصدير يستخدم النتائج المطابقة؛ أقصى 10000 سجل. طباعة العضو للمستخدمين المصرح لهم بالتصدير.

الاستيراد: نزّل القالب، استخدم أسماء الكليات والأقسام المطابقة، ارفع XLSX، اختر الورقة واربط الأعمدة، راجع الصفوف. التأكيد يحفظ الصالح فقط ويتخطى التكرار. احتفظ بتقرير الأخطاء لمعالجة الصفوف ثم أعد رفعها.

الحذف المنطقي للأعضاء للمدير فقط. افتح الفلاتر واختر المحذوفة ثم استعادة. إزالة المرفق تخفيه وتحتفظ بالنسخة؛ الحذف النهائي غير متاح قبل اعتماد سياسة احتفاظ المؤسسة.
