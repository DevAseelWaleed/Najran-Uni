# النشر ومتطلبات التشغيل

1. خادم Node 22.12+، PostgreSQL 16+، ومساحة ملفات خاصة مع نسخ احتياطي. قاعدة البيانات ليست خدمة عامة.
2. `npm ci`, `npm run db:generate`, `npm run build`, `npm run db:migrate`.
3. تثبيت Chromium `npx playwright install --with-deps chromium` في Linux. الخط العربي مضمن من @fontsource/cairo. يحتاج Chromium مساحة وذاكرة كافيتين، لا تعطّل sandbox دون تصميم مناسب للحاوية.
4. NODE_ENV=production، APP_ORIGIN=https://نطاق-المؤسسة، SESSION_SECRET عشوائي قوي، SMTP حقيقي يدعم TLS، STORAGE_DIR خارج public. صلاحيات قراءة/كتابة محصورة بحساب الخدمة.
5. `npm run start -w apps/api` خلف reverse proxy. تقديم apps/web/dist مع fallback إلى index.html؛ تمرير /api إلى 127.0.0.1:3000. الخادم يستمع على loopback افتراضيًا. لا تعرض API مباشرة للإنترنت.
6. تهيئة أول مدير بمتغيرات صريحة ثم حذف ADMIN_PASSWORD من البيئة.
7. تشغيل اختبارات النظام والنسخ الاحتياطي والاستعادة على بيئة staging قبل اعتماد النشر.

## تهيئة البريد

التهيئة الافتراضية الحالية هي Gmail: `smtp.gmail.com`، المنفذ 465، `SMTP_SECURE=true`، وحساب المرسل نفسه في SMTP_USER وSMTP_FROM. أضف كلمة مرور تطبيق Google في SMTP_PASSWORD محليًا ثم شغّل `npm run mail:verify` وأعد تشغيل الخادم. الأسرار لا توجد في المستودع. راجع [تعليمات كلمات مرور التطبيقات](https://support.google.com/accounts/answer/185833) و[وثائق Gmail SMTP](https://developers.google.com/workspace/gmail/imap/imap-smtp).

SMTP_HOST,SMTP_PORT,SMTP_SECURE,SMTP_USER,SMTP_PASSWORD,SMTP_FROM. المنافذ 465 مع secure=true أو 587 مع STARTTLS. الإنتاج يطلب TLS ويرفض المضيفات المحلية. إعداد SPF/DKIM/DMARC لدى مزود الجامعة للتحقق من التسليم الفعلي. لا يُعد التسليم إلى البريد الجامعي متحققًا باستخدام المستقبل المحلي.

## سياسة التشغيل

- جلسات 8 ساعات؛ لا تستمر بعد تعطيل الحساب أو تغيير الدور/البريد أو تغيير كلمة المرور.
- تقييد الطلبات داخل عملية الخادم؛ للإنتاج متعدد النسخ استخدم تقييد معدل مشترك وطبقة proxy تحافظ على هوية العميل بأمان. لا تفعل trust proxy عشوائيًا.
- TRUST_PROXY_HOPS=0 افتراضيًا. اضبطه إلى 1 أو 2 فقط بعد التحقق من عدد طبقات proxy الموثوقة ومنع الاتصال المباشر بالخادم.
- نسخ احتياطي مشفر لقاعدة البيانات والملفات، وجدولة تنظيف الجلسات والتحديات المنتهية بعد اعتماد سياسة احتفاظ الجامعة.
- MALWARE_SCANNER مسار executable يأخذ مسار ملف ويعيد exit 0 إذا نظيف. اربط ClamAV أو ماسح المؤسسة قبل إتاحة الرفع على نطاق عام. الافتراضي فحص توقيع/حجم فقط.
- مراقبة صحة قاعدة البيانات والبريد ومساحة التخزين وسجل الأخطاء، دون كلمات مرور أو رموز.
- لا يوجد نشر تلقائي في هذه المهمة؛ النطاق والاستضافة والشعار والبريد النهائي مدخلات المؤسسة.
# الشعار المرفق

عند نقل الخادم إلى الاستضافة، انقل مجلد `apps/api/assets` إلى جانب `apps/api/dist`؛ يحتوي نسخة الشعار الأصلي التي تستخدمها الواجهة وتقارير PDF افتراضيًا. لا تعِد ضغط الصورة أو قصها.
